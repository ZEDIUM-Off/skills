# Skills favoris

Ce dépôt contient une sélection de skills que je souhaite partager.

## Skills inclus

- [`plan-writer`](./plan-writer/) — aide à rédiger des plans d’implémentation structurés.

## Installation

L’installation se fait avec le CLI [`skills`](https://www.skills.sh/docs) :

```bash
npx skills add ZEDIUM-Off/skills
```

Le CLI installe les skills du dépôt et les rend disponibles pour votre agent compatible.
